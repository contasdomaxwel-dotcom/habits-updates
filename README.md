# Habits — atualizações

Arquivos de instalação (APK) do app **Habits**: hábitos, estudos e Samsung Health no celular e no tablet.

- **Baixar a versão mais recente:** https://samsung-habit.web.app (ou na seção [Releases](../../releases/latest)).
- Com o Habits instalado, as versões novas aparecem no próprio app em **"Há uma atualização disponível"**: é só tocar em **Atualizar**.

Este repositório guarda só os APKs. Cada versão é publicada pelo script `scripts/publicar-atualizacao.mjs` do projeto, que também atualiza o aviso que o app consulta (`https://samsung-habit.web.app/update/latest.json`).
